# P4 增量报告：BGM 闪避与淡入淡出

日期：2026-10-25
范围：配音侧链闪避、BGM 淡入淡出、项目持久化

---

## 1. 已实现

### 1.1 配音闪避（ducking）
- MP4 混音时用 `sidechaincompress`：
  - 主输入：BGM；
  - 侧链：正片音轨（配音/原声）；
  - 参数：threshold 0.05、ratio 6、attack 15ms、release 300ms。
- 解说一进来，BGM 自动压低；停顿后回弹，不需要手调关键帧。
- 草稿里仍是固定音量（剪映侧链要额外关键帧，暂不做）。

### 1.2 淡入淡出
- BGM 自动加 `afade`：
  - 淡入 1.2s；
  - 淡出 1.2s（总长不足 4.8s 时按总长 1/4 收缩）。
- 解决循环接缝和片头/片尾硬切。

### 1.3 开关与持久化
- 项目新增 `bgmDucking` / `bgmFade`，默认都开。
- 导出页「BGM 处理」行：
  - `配音闪避`、`淡入淡出` 两个开关；
  - 文案标明「闪避约 -12dB，淡入淡出 1.2s」。
- 切换立即写回项目，重开仍保留。

## 3. 限制

- **草稿不做 ducking**：BGM 轨仍是固定音量；剪映里要闪避需手动加关键帧。\n- 闪避强度已支持轻/中/强三档；草稿仍不跟随。
- **没有响度归一化**：不同 BGM 的响度差仍靠音量滑杆。
- **淡入淡出只作用于 BGM**，不是整片画面/声音的淡入淡出。
- 侧链参数固定，暂不能按项目调阈值/比率。
- 原声仍是视频轨内嵌，没有独立音轨。
- 硬件编码、多集批量、安装包未做。
