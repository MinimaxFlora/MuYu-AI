# 「幕语」产品与 UI 设计方案 v0.1

> 工作名：**幕语**（Muyu Studio）—— 把一部片，讲成一条爆款。
> 定位：NarratoAI 的**桌面级重构**：同一条流水线，但从“表单 + 生成按钮”升级为“素材 → 文案 → 分镜 → 成片”的可视化创作台。
> 技术：Tauri 2 + Rust + Vue 3 + TypeScript + Naive UI。
> 配套高保真稿：`design/screens/*.png`（首页 / 文案 / 分镜 / 导出），可交互 HTML 在 `design/mockups/`。
> 本文是**设计冻结稿**，确认后才进入实现。

---

## 1. 设计判断

NarratoAI 的能力很强，但它把 30+ 个参数摊在一屏：第一次用的人不知道该先点哪；生成完只能看进度条；文案是整段 textarea；分镜是一张 JSON 表格。
我们要做的不是“换个皮”，而是把它的流水线**产品化**：

1. **把线性流水线变成 5 个可停留的步骤**，每步都能预览、能改、能回退。
2. **把 JSON 变成时间轴**：画面、解说、配音、原声、BGM、字幕在一条时间线上对齐。
3. **把“等结果”变成“可干预”**：文案审核点、单句重写、单镜重配、失败断点续跑。
4. **把参数收进“检查器”**：默认只给 5 个关键选择，高级参数点开才出现。

一句话原则：**默认一键成片，专家随时接管。**

## 2. 信息架构

```
幕语
├── 首页 Home                 概览 / 继续创作 / 任务队列 / 引擎状态
├── 项目 Projects             全部草稿与成片（网格 / 列表 / 筛选）
├── 素材 Assets               视频、字幕、音频、BGM、音色样本
├── 任务 Tasks                转写、分析、配音、渲染队列（可暂停/重试）
├── 设置 Settings             模型 / 声音 / 字幕 / 合成 / 存储 / 快捷键
└── 创作工作台 Studio（独立全屏）
    ├── 1 素材   导入、多集、截取范围、字幕
    ├── 2 理解   剧情理解、人物关系、分集脉络
    ├── 3 文案   逐句解说、AI 改写、时长预估
    ├── 4 分镜   时间轴、OST、配音、对齐
    └── 5 成片   渲染、剪映草稿、字幕导出
```

导航规则：
- 全局左栏只放「首页 / 项目 / 素材 / 任务」，**创作**是主按钮，不在导航里常驻。
- 进入工作台后左栏收起为 72px 图标条，把宽度让给内容；顶部出现项目名与步骤条。
- 设置是全局页，工作台内以右侧抽屉打开「本次项目的局部设置」，不跳出流程。

## 3. 五个核心流程

### 3.1 首次使用（3 分钟到第一条片）
`首页 → 新建 → 导入视频（自动找同名字幕）→ 选「短句解说」→ 选音色 → 开始`
默认走「全自动」，只在文案生成后停一次，给用户 30 秒审核；点「继续」就出片。

### 3.2 一键成片（熟练用户）
首页 `⌘N` → 拖入多集 → 回车 → 后台跑；顶部任务胶囊显示阶段与剩余时间；完成后弹「成片就绪」卡片，可直接播放/打开目录/导出剪映。

### 3.3 逐句精修（核心差异化）
文案页：左侧字幕、中间逐句卡片、右侧参数。点某句 → 左字幕自动滚到对应时间；工具条「更短 / 更狠 / 换钩子 / 重写」；每句实时显示「字数 → 预计秒数」，超过画面承载时标黄提示。

### 3.4 分镜微调
分镜页：上方预览、中间分镜表、下方时间轴。拖时间轴边缘改镜头长度；把 `OST=1` 拖成 `OST=0` 会提示「该段将去原声并重新配音」；右侧检查器可换音色/音量/转场。

### 3.5 批量出片
多集项目 → 「批量」→ 每集一条成片；任务页显示矩阵进度；失败的单集可单独重跑，不影响其他集。

- 主 CTA 金色实心「＋ 新建解说」，次 CTA 幽灵「导入链接」。
- 「继续创作」只展示**最近一个未完成**项目，避免选择困难。
- 项目卡：16:9 封面（取视频第 3 秒帧）、模式徽章、时长、状态点、底部进度细线；hover 出现「继续 / 复制参数 / 删除」。
- 空态：三步插画式引导（导入 → 选模式 → 出片），带 30 秒示例项目。

### P1 新建向导（右侧 480px 抽屉，4 步）
1. **素材**：拖拽区 / 链接输入 / 多集列表；每集一张卡（时长、分辨率、截取范围滑块、字幕状态）。识别到同名 `.srt` 自动挂载并提示。
2. **模式**：5 张卡，带「适合 / 产出 / 预计耗时」；短句解说卡标注「一句一镜 · 8–24 字」。
3. **参数**：只露 5 项——类型、解说语言、目标时长、原片占比、音色；「更多设置」展开比例/字幕/模型。
4. **确认**：左侧参数摘要，右侧流程预览（5 个阶段与预计时间）；两个按钮：「全自动」「文案后暂停（推荐）」。

- 句卡是本页的原子单位：序号、正文（可直接编辑）、`字数 · 预计秒数`、hover 工具条。
- 超长句（> 32 字）标黄并提示「建议拆分」；一句拆成两句时自动重排编号。
- 右侧统计随编辑实时更新；「覆盖 92%」= 文案预估时长 / 原片有效时长，低于 70% 提示「会显得空」。
- 底部常驻「AI 续写」输入框：贴一段参考文案或一句要求，回车续写。

- OST 用颜色编码：金 = 解说，青 = 原声，紫 = 混合；时间轴同色，一眼看出节奏。

### P5 设置

左侧二级导航：**模型服务 / 声音 / 字幕 / 合成 / 存储 / 通用**。
- 模型服务：视觉模型、文本模型、搜索（Tavily）三组；每组「主模型 + 快速模型 + 测试连接」，Key 用密码框，显示来源与安全提示。
- 声音：引擎卡片网格（Edge / Azure / 腾讯 / Qwen3 / 豆包 / IndexTTS / IndexTTS2 / OmniVoice / VoxCPM ×2），本地引擎带「服务地址 + 连接状态」；下方音色库（搜索/试听/收藏）。
- 字幕：字体、字号、颜色、描边、位置、预设（影院白/黑底白/描边黄）、原字幕遮罩（可视化框选，横竖屏两套）。
- 合成：FFmpeg 引擎检测、硬件加速、并发数、缓存目录、默认编码。
- 存储：项目体积、缓存清理（抽帧/片段/任务）、输出目录。
- 通用：语言、主题、快捷键、更新。

> 设置里的所有“引擎卡片”都可一键测试连通性，失败给出**可执行**的中文建议（域名、Key、端口、模型名）。

## 5. 设计系统

### 5.1 色彩（Cinema Noir）
| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#08090D` | 应用底色 |
| `--surface` | `#0F1219` | 面板 |
| `--surface-2` | `#151924` | 卡片/悬浮 |
| `--line` | `rgba(255,255,255,.07)` | 分隔线 |
| `--text` | `#EDEFF5` | 主文字 |
| `--text-2` | `#A5ABBA` | 次文字 |
| `--text-3` | `#6B7280` | 辅助 |
| `--gold` | `#E9B949` | 主品牌 / 主 CTA / OST=0 |
| `--gold-soft` | `#F6D382` | 高光 |
| `--violet` | `#8B7CFF` | AI 动作 / OST=2 |
| `--cyan` | `#45C8BE` | OST=1 / 成功态辅助 |
| `--red` | `#FF6B6B` | 错误 / 删除 |
| `--green` | `#3DDC97` | 完成 / 在线 |

规则：金色只用于**主行动**与**解说轨**；AI 相关动作统一紫；状态色不做大面积填充，只做点、线、徽章。

### 5.2 字体
- 中文：`MiSans` → `HarmonyOS Sans SC` → `Microsoft YaHei UI`
- 西文/数字：`Inter`，时间码与统计数字用 `Bahnschrift`（等宽感）
- 字号：12 / 13 / 14 / 16 / 20 / 24 / 32；正文 14，文案卡正文 18/1.8，标题 20–24
- 字重：400 / 500 / 600；标题用 600，不用 700（避免糊）

### 5.3 间距与形状
- 8pt 网格；页面边距 28；面板间距 16；卡片内边距 20
- 圆角：控件 10，卡片 14，面板 18，胶囊 999
- 阴影：`0 1px 0 rgba(255,255,255,.04) inset, 0 12px 32px rgba(0,0,0,.45)`
- 玻璃：`backdrop-filter: blur(20px)` 仅用于顶栏、浮层、播放器控件

### 5.4 动效
- 入场 160ms `cubic-bezier(.2,.8,.2,1)`；面板 220ms；播放头线性
- 只动 `transform/opacity`；进度用宽度但限制 60fps 场景
- 生成中：骨架 + 呼吸光，不用无限旋转 spinner 抢占注意力

### 5.5 图标
- 线性 1.5px，24 网格；OST/轨道用色块 + 形状双编码（不只靠颜色）

### 5.6 Naive UI 映射
| 设计 | Naive UI |
|---|---|
| 深色主题 | `darkTheme` + `GlobalThemeOverrides` |
| 主色 | `primaryColor: #E9B949`，`primaryColorHover: #F6D382` |
| 圆角 | `borderRadius: 10px`，卡片 `14px` |
| 面板 | `NCard` + 自定义 class（去默认边框，加内高光） |
| 左栏 | `NLayoutSider` + `NMenu`（collapsed-width 72） |
| 步骤条 | `NSteps`（自定义 dot 样式） |
| 分镜表 | 自研虚拟表格（`NDataTable` 性能不够，行高 56 + 缩略图） |
| 时间轴 | Canvas/DOM 混合自研（`@vueuse/core` + 自绘） |
| 播放器 | `<video>` + 自绘控件（不用第三方皮肤） |
| 通知 | `NNotification` + 任务胶囊 |
| 设置表单 | `NForm` + `NFormItemGi` 栅格 |

## 6. 短句解说（显式模式，差异化）

| 项 | 规则 |
|---|---|
| 句长 | 8–24 字（默认 14–18），超过 28 字标黄，超过 32 字自动建议拆分 |
| 结构 | 一句一镜；一句只讲一个信息点；禁止一句话跨两个事件 |
| 节奏 | 每 3–5 句一个小钩子；每 60–90 秒一个反转/升级 |
| 时长 | `预计秒数 = 字数 / 5`（中文），与实际 TTS 时长误差 > 20% 时提示 |
| OST 配比 | 默认 30% 原声；纯解说段落连续不超过 45 秒 |
| 开头 | 前 3 句必须完成「人物困境 + 反常信息 + 悬念」 |
| 结尾 | 最后一句必须留问题/新危机，不总结 |

交互上单独给一个「短句」密度滑杆（疏 / 标准 / 密），实时反映在句数与预计时长上。

## 7. 状态设计

| 状态 | 表现 |
|---|---|
| 空 | 插画 + 一句解释 + 一个主按钮，不堆文字 |
| 加载 | 骨架屏，保留布局；超过 3 秒显示阶段名与已用时 |
| 生成中 | 顶部任务胶囊 + 面板内阶段进度；可最小化到任务页 |
| 失败 | 就地错误卡：原因（人话）+ 建议动作 + 「重试此步」 |
| 离线 | 顶部黄条；云端引擎置灰并标注「需联网」；本地引擎仍可用 |
| 无权限/Key 失效 | 设置页对应卡片红点 + 一键跳转 |

## 8. 快捷键

## 9. 技术架构（设计约束）

```
Vue 3 + TS + Naive UI + Pinia + Vue Router
        │  Tauri IPC (commands + events)
Rust (src-tauri)
├── core      配置、项目库(SQLite)、路径、日志、密钥(OS keychain)
├── media     ffprobe/ffmpeg 封装、抽帧、裁剪、拼接、混音、字幕烧录、硬件加速探测
├── asr       SRT 解析、Fun-ASR/FireRed/百炼 客户端、翻译/校准
├── llm       OpenAI 兼容、Gemini 原生、TwelveLabs、Tavily、重试/降级/流式
├── tts       Edge/Azure/腾讯/豆包/Qwen3/IndexTTS/OmniVoice/VoxCPM 客户端
├── pipeline  5 种模式的状态机、步骤产物、断点、并发、进度事件
├── export    剪映草稿、SRT/文案、成片
└── fetch     yt-dlp sidecar（抖音/B站/YouTube 链接解析）
sidecars: ffmpeg.exe / ffprobe.exe / yt-dlp.exe / (可选)本地模型 HTTP Pack
```

约束：
- 所有网络请求走 Rust，前端不直连第三方，Key 不进前端。
- 每一步产物落盘（`project/steps/*.json`），支持任意步骤重跑。
- 长任务用 `job_id + 事件流`，前端只订阅状态，不阻塞 UI。
- 本地模型统一 HTTP 协议，未来新增引擎只加一个 provider。

## 10. 设计验收标准

1. 1600×1000 与 1280×800 下无横向滚动、无控件遮挡；175% 缩放下字号与按钮不裁切。
2. 从首页到出片，主流程不超过 6 次点击（全自动路径）。
3. 任一失败状态都能在**当前页**看到原因与重试入口。
4. 文案页单句编辑延迟 < 16ms；分镜表 500 行滚动不掉帧。
5. 颜色对比度：正文 ≥ 4.5:1，次要文字 ≥ 3:1。
6. 所有 icon-only 按钮都有 tooltip 与 `aria-label`。
