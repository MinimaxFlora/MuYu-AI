# P4 增量报告：原声独立轨、可调闪避、批量渲染

日期：2026-10-25
范围：剪映五轨、闪避强度、多项目串行队列

---

## 1. 原声独立轨（剪映五轨）

之前原声靠视频 segment 的 `volume` 控制。现在改为真正的独立音轨：

1. 对每个 `OST=1/2` 的镜头，用 ffmpeg 把原声抽成 `assets/audio/original_XXX.wav`（48kHz 立体声）。
2. 视频轨所有 segment 音量设为 0，避免原声重复。
3. 新增「原声」音轨，按时间码铺开。
4. 最终草稿为五轨：

```
视频 / 原声 / 配音 / 字幕 / BGM
```

验证：样例项目 3 镜（OST=0,0,1）→ `tracks=5`、`assets=5`、`duration=11.759s`，`original_003.wav` 存在。

## 2. 可调闪避强度

项目新增 `duckingStrength`，三档：

| 档位 | threshold | ratio |
|---|---|---|
| 轻 | 0.03 | 3 |
| 中 | 0.05 | 6 |
| 强 | 0.08 | 10 |

- 导出页「BGM 处理」里的下拉选择，切换即写回项目。
- 只影响 MP4 侧链压缩；剪映草稿 BGM 仍是固定音量。

## 3. 批量渲染

### 3.1 UI
- 新增 `/tasks`「批量渲染」页，AppRail「任务」入口启用。
- 读取所有项目，逐个计算：
  - 镜头数、配音条数、缺配音数量、是否就绪、上次渲染。
- 只允许勾选已就绪项目；支持全选/清空。
- 共用设置：比例、分辨率、编码器、字幕烧录。
- 每个项目使用自己的 BGM / ducking / 字幕设置。

### 3.2 队列
- 纯前端串行队列：逐个项目调用现有 `render_video` 命令。
- 实时进度：`render://progress` 映射到当前项目。
- 单个项目失败不阻断后续，结果列表分别标记成功/失败。
- 支持停止：`cancel_render` 软取消，当前镜头结束后终止队列。
- 每个项目渲染完自动写回 `lastRender`。

## 4. 限制

- **队列不持久化**：关闭应用后队列丢失，不会自动续跑。
- **串行**：同时只渲染一个项目；没有并发/优先级。
- **共用设置**：批量页不能给单个项目单独设比例/分辨率/编码器；项目内 BGM/ducking 仍独立。
- **剪映草稿仍未在剪映内打开验证**。
- 原声抽取失败会直接中止该草稿，不会静默降级。
- 安装包已构建（未签名），见 `13-architecture.md` 发布结果。
